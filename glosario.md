## Selector

> Indica qué elemento HTML quieres modificar con CSS.

## section

> Selecciona todas las etiquetas <section>.

## .algo

> Selecciona elementos que tienen la clase algo.

## #algo 

> Selecciona el elemento que tiene el ID algo.

## Margin
> Espacio fuera del elemento.

## Padding

> Espacio dentro del elemento.

## Border

> Borde que rodea el elemento.

## Modelo de caja

> Forma en que CSS organiza contenido, padding, border y margin.

## DevTools

> Herramientas del navegador para revisar y modificar una página.

## Color

> Se puede escribir con hexadecimal (#222), rgb() o nombres (blue).

## Paleta

> Conjunto de colores usados en una página.

## Flexbox

> Permite organizar elementos, por ejemplo, poner dos elementos lado a lado.

## let

> Se usa para una variable cuyo valor puede cambiar.

## const  

> Se usa para una variable cuyo valor no cambia.

## String

> Es un dato de texto. Ejemplo: "Hola".

## Number

> Es un dato numérico. Ejemplo: 25.

## Boolean

> Puede tener dos valores: true o false.

## Función

> Es un bloque de código que realiza una tarea.

## return

> Indica el valor que una función devuelve.

## Objeto { }

> Guarda datos relacionados en propiedades. Ejemplo: obra.nombre.

## Punto .

> Permite acceder a una propiedad de un objeto.

## Arreglo [ ]

> Guarda varios valores en una lista.
