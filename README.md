# Clima-obra
## ¿Qué hace la página?
La página muestra información del clima actual, como la temperatura, humedad, precipitación y velocidad del viento. Los datos se obtienen mediante una API y se muestran en la página web.

### Liga pública
La página está publicada en GitHub Pages.

http://emitostado.github.io/clima-obra/

## ¿Qué API usa?
La página utiliza la API de Open-Meteo para obtener los datos del clima.

## ¿Cómo correrla en mi computadora?
Para correrla en la computadora se deben descargar o clonar los archivos del proyecto y abrir el archivo index.html en un navegador. También se necesita conexión a Internet para que la página pueda obtener los datos de Open-Meteo.

## ¿Qué aprendí?
Aprendí cómo funciona una página web y cómo se comunica con un servidor mediante peticiones HTTP. También aprendí a utilizar una API para obtener datos del clima, a leer información en formato JSON y a acceder a sus datos mediante rutas con punto. Además, aprendí a utilizar la pestaña Network y la consola de DevTools para identificar errores, y a utilizar try...catch para manejar errores en JavaScript.
